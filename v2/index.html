01进阶版

专业版

措辞克制、术语更多、结构更密。适合专业用户和深度使用者，也适合把图拿去讨论、交付、存档。

  • 三条路各自的收益、代价、成立条件与可撤回性
  • 待确认缺口分级编号，跨轮次保持稳定
  • 支持多轮更新：补条件、勾反转、记上一轮的结果
  • 可导出流程图 / 分享图 / Markdown

02大众版

人性版

口语化、直接戳情绪，把话说得更容易听懂。适合第一次接触的人，也适合在情绪最乱的时候用。

  • 同样的事实、缺口、三条路，换一种更直白的说法
  • 不绕弯子：先说你最想听的那句，再给依据
  • 同样支持多轮更新与导出
  • 手机上读起来更轻松

使用前，三件小事

两个版本能力完全一样，区别只在说话方式，选你读得下去的那个就好。
不用注册、不用登录：这是纯前端页面，你的输入、历史和 API Key 只存在你自己的浏览器里，不经过任何服务器。
接 AI 需要你自己的 Key：DeepSeek / 通义千问 / Kimi / 硅基流动等任选其一；不配也能用本地引擎，30 秒出一张规则版的图。
