02 / 它给你什么

你缺的不是勇气，
是一张能检查的图。

卡住的时候，三样东西通常混在一起：已经确定的事实、其实只是猜测的判断、和真正需要先去确认的条件。混在一起，任何选择看起来都像赌博。

A · 已知事实

只贴你写过的原话

每条事实都逐字来自你的输入，并标注「用户自述 · 未独立核实」。不替你补脑，也不假装知道你不知道的事。

B · 待确认缺口

不知道就说不知道

没底的部分单独成列、编号，不硬下结论。你一眼能看出来：现在到底还差哪几件事。

C · 三条路

先找那条第三条路

A / B 之外，它会先找一个成本更低、还能撤回的做法——为的是让你有退路，而不是逼你现在就全押。

D · 下一步小实验

48 小时内能做的一件小事

不是「你要勇敢一点」，而是「这周先打一个电话，问清三件事」。能立刻执行，才叫下一步。

E · 改主意条件

什么信号出现，就该换方向

它不会说「你应该去」，而是说「如果对方给的岗位和现在说的不一致，这条倾向就要改」。判断权留给你。

F · 拿来用

导得出来，也带得走

分享图、Mermaid 流程图、完整 Markdown 都能导出，贴进文档或发给要一起做决定的人；手机上也能直接存图。

03 / 凭什么可信

它不装懂。
这一点写在产品里。

大多数「AI 建议」的问题是：听起来全对，但没法检查。这里的每条结论都能追回你写过的原话，或者被明确标成「猜测」。

原则 01

原话就是原话

每条「已知事实」都逐字取自你的输入，旁边标着「用户自述 · 未独立核实」。它不替你把猜测写成事实。

原则 02

不知道，就说不知道

没底的部分单独成列，不进结论。你一眼能看出来：现在到底还差哪几件事。

原则 03

给条件，不给口号

不说「你应该」，只说「如果你更在意 X，就先走 Y；如果 Z 发生，就改回来」。判断权在你手里。

原则 04

先小试，别梭哈

优先推荐成本低、还能撤回的动作。为的是让你有退路，而不是逼你现在就全押。

原则 05

不用注册，也没有服务器

纯前端单文件页面：没有账号系统、没有后台，不把你的内容上传给我们。写完关掉，内容只在你自己的浏览器里。

边界

它不是算命，也不替你做决定

它不具备法律、医疗、财务资质，不能预测未来。它能做的是把你已经知道、但混在一起的思考，整理成可以逐条检查的结构。

04 / 常见问题

选之前，
你可能想问的五件事。

如果这里没有，页面底部有 GitHub 仓库，可以直接开 issue 问。

专业版和人性版到底有什么区别？+

只有措辞不同。两个版本的分析口径、报告结构（全貌 / 凭什么这么说 / 那我现在干嘛）、导出能力完全一样。专业版更克制、术语更准，适合讨论与交付；人性版更口语、更直接，适合第一次用或情绪最乱的时候。

选错了要重新写吗？+

不用。进入任意版本后，顶部都能一键换另一个版本，也可以随时回到这个选择页重新挑。两版处理的是同一份输入，切换不会丢掉你写的内容。

要花钱吗？+

工具本身免费。不配 API Key 也能用本地引擎出一版规则图。只有当你选择云端模型时，才需要自己的 Key，费用由服务商按 token 收取——几百字的问题通常是几分钱到几毛钱的量级。

我写的东西会被谁看到？+

不经过我们的服务器——这个项目没有后端。本地引擎完全离线；云端引擎时，你的内容会从浏览器直接发给你选择的服务商，按对方的隐私政策处理。Key 和草稿都只存在你本机浏览器里。

手机能用吗？+

能。同一个网址，手机浏览器打开即可，布局会自适应；用手机上的 Key 也只需要配置一次。

旧版还在吗？

在。v2 时代的入口全部保留，网址不变：/pro/、/human/、/v2/。你可以拿它们和 v3 对照着看，也可以继续用旧版。
